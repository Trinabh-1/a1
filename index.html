Your key goes straight from this page to TBA's API — never sent anywhere else. Runs a real offense/defense least-squares regression over every qual match (not TBA's precomputed OPR): mean is well-validated (~0.95 correlation with true power). Variance is rougher — one event's matches aren't enough to pin per-team consistency down precisely; treat variance differences as suggestive, not exact. Want your key hardcoded so you don't retype it? Open this file in a text editor, find HARDCODED_TBA_KEY near the top of the script, paste your key between the quotes, and save.
